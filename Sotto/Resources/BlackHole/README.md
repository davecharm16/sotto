# BlackHole Virtual Audio Driver

BlackHole 2ch is a free virtual audio driver required for Sotto to route processed audio.

## Download Options

1. **Official Website** (recommended): https://existential.audio/blackhole/
   - Enter your email to receive the download link
   - Download the 2ch version

2. **Homebrew**: `brew install blackhole-2ch`

## For Bundling (Optional)

If you want to bundle the installer with Sotto:
1. Download BlackHole-2ch.pkg from the official site
2. Place it in this directory as `BlackHole-2ch.pkg`

The app will detect if BlackHole is not installed and guide users to install it.

## Codex plan review (2026-11-03) — adopted
- BlackHole gate was too broad: build a **hardware-independent core** (`PipelineCore`: ring A -> converter -> NC ->
  drift -> ring B) fed by deterministic PCM/clock-rate fixtures. Only device routing + the listen test need BlackHole.
- Tier A (offline, headless, in `SottoCoreTests`): CA1 ring, CA4 NC pump + format/channel/continuity checks,
  CA5 drift with bounded correction (max adjust, crossfade, ring bounds; +/- ppm; startup transient).
- Tier B (devices): CA2/CA3 engines, CA6 lifecycle (permission revoked, format change, duplicate config notices,
  partial start failure; NC thread joins before df_destroy; silence after capture loss).
- Tier C: S4/S5 then one integration matrix (first launch, denied, no device, saved 0 attenuation, restart).
- CA3 acceptance: define "routing log" = both engines' device UID + negotiated format; zero-alloc measured by review
  of block bodies + counters (no malloc in Instruments/`MallocStackLogging` over 60 s if available).

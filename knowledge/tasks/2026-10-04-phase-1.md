## Outcome / Review
Done on 2026-10-04. The orchestrator re-ran everything in the main tree after the merge.
- **Rust:** `cargo test --release --locked`: **7/7 pass.**
  - Noise only: pink −23.90 dB, white −43.56 dB.
  - SI-SDR: +14.15 / +12.00 dB (white) and +10.12 / +8.17 dB (pink), at 0 / 5 dB SNR.
  - Clean speech changes level by −0.21 dB.
  - Latency is 1440 samples. p99 is 0.753 ms per frame.
  - Bypass is bit-exact. The slider curve is monotonic, with 0.5 and 1.0 6.88 dB apart. A toggle steps by at most
    −60 dB. The concurrency stress test is clean; there is no TSan, because no nightly toolchain is installed.
- **App:**
  - Debug `test` passes: `NCProcessorSmokeTests` (headless) and `SottoTests`.
  - Release `build` passes, arm64 only.
  - The `.a` exports exactly the 6 `_df_*` symbols and is 47.5 MB.
- **Signing:** `Authority=Apple Development: davecharm16@gmail.com`, `TeamIdentifier=5QT5U69BN8`, the `runtime`
  flag is set, and the designated requirement is not a cdhash.
- **Hotkey:** `grep addGlobalMonitor Sotto/` finds nothing. The Carbon hotkey handler was verified through
  `osascript`.

**Deviations from the plan:**
- The dsp lane dropped `lto = true`. Cargo can't LTO a lib that also builds an `rlib`, and LTO made the `.a`
  123.6 MB of bitcode with no speed gain.
- `DeepFilter/.cargo/config.toml` pins `MACOSX_DEPLOYMENT_TARGET`, and the pre-build script unsets the variable
  Xcode exports. See lesson `xcode-env-leaks-into-cargo-and-tests`.
- The root `.gitignore` no longer ignores `Cargo.lock`.
- The worktree branched from `main`, not this branch. That was harmless, because `DeepFilter/` was identical on
  both. The `/sotto-team` skill now notes it.
- On the pink-noise case at 5 dB SNR, SI-SDR came in at +8.17 dB, below the spike's +10. It uses different
  (CMU ARCTIC) speech, and it still clears the +6 dB bar.
